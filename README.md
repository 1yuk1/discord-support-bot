# 🤖 Discord Support Bot (SinusSMP)

Умный AI-бот технической поддержки для Discord-сервера с интеграцией OpenRouter, векторной базой знаний (RAG на ChromaDB), распознаванием изображений (Vision), защитой от спама и системой эскалации на персонал.

---

## 🌟 Основные возможности

- 🧠 **AI-интеллект (OpenRouter + Vision)**:
  - Поддержка любых современных языковых моделей через OpenRouter (gpt-4o-mini, claude-3.5-sonnet, gemini-1.5-flash и др.).
  - Распознавание скриншотов чеков и ошибок лаунчера (Vision через Base64).
  - Резервный AI-провайдер с автоматическим переключением при сбоях (Circuit Breaker).
  - Склейка быстрых сообщений пользователя (Message Debounce), чтобы не спамить ответами и экономить токены.

- 📚 **База знаний и RAG (ChromaDB + Markdown)**:
  - Хранение статей и инструкций в формате Markdown (knowledge/*.md) с автоматической нарезкой по секциям (## Заголовки).
  - Совместимость со структурированными JSON-файлами (knowledge/*.json).
  - Локальная модель мультиязычных эмбеддингов intfloat/multilingual-e5-large-instruct.
  - Гибридный поиск: точное сопоставление игровых слэш-команд (/ps, /crafts, /mine, /garant) + векторный семантический поиск.
  - Порог релевантности (distance_threshold = 0.40): спам и отвлеченные вопросы отсекаются, не расходуя токены контекста.
  - Безопасное обновление базы знаний без блокировок на Windows (upsert).

- 👥 **Умная эскалация на человека (Human Escalation)**:
  - Автоматическое распознавание прямых просьб позвать человека (RU / EN).
  - Детекция критических тем: взлом аккаунта, сброс пароля, обжалование наказаний.
  - Служебный маркер [TRANSFER_TO_HUMAN] от LLM с автоматическим переводом тикета в режим human_mode.

- 🛡️ **Модерация запрещенных упоминаний**:
  - Защита администраторов и ролей от несанкционированных пингов.
  - Автоматическая прогрессивная лестница таймаутов в Discord (1 мин → 10 мин → 1 час → 1 день).

- ⏰ **Напоминания персоналу (Staff Reminders)**:
  - Отслеживание тикетов, где игрок ждет ответа дольше заданного времени (idle_hours).
  - Генерация краткой сводки через LLM и пинг роли поддержки.
  - «Тихие часы» (quiet_hours) в ночное время с учетом часового пояса.

- 🚨 **Динамическая система инцидентов**:
  - Команда /incident add позволяет на лету добавить известную проблему, и бот сразу учитывает её во всех ответах без перезапуска.

- 🌐 **Русская локализация команд**:
  - В русской версии Discord все слэш-команды отображаются на русском языке (/стоп, /старт, /инцидент, /модель, /сводка, /настройки).

## 🛠️ Установка и запуск

### 1. Требования
- Python 3.11+
- Установленные зависимости из 
equirements.txt

### 2. Установка зависимостей
`ash
pip install -r requirements.txt
`

### 3. Настройка конфигурации
Сгенерируйте settings.toml из переменных окружения или отредактируйте его вручную:
`ash
python scripts/generate_settings.py
`

Основные переменные окружения:
| Переменная | Описание |
|---|---|
| DISCORD_TOKEN | Токен вашего Discord-бота |
| OPENROUTER_API_KEY | API ключ OpenRouter |
| OPENROUTER_MODEL | Идентификатор основной модели (напр. openai/gpt-4o-mini) |
| SUPPORT_CATEGORY_IDS | ID категорий каналов тикетов (через запятую) |
| STAFF_ROLE_IDS | ID ролей персонала |
| REMINDER_PING_ROLE_IDS| ID роли для пинга при напоминаниях |

### 4. Индексация базы знаний
Перед первым запуском или после добавления новых файлов в knowledge/:
`ash
python indexer.py
`

### 5. Запуск бота
`ash
python -m bot
`

## 📋 Команды администратора

| Команда | Описание |
|---|---|
| /stop (/стоп) | Выключить бота в текущем тикете |
| /start (/старт) | Включить бота в текущем тикете |
| /status (/статус) | Проверить статус бота и режим в канале |
| /resume_bot (/вернуть-бота) | Снять режим передачи человеку (human_mode) |
| /clear_history (/очистить-историю) | Очистить контекст диалога в тикете |
| /summarize [limit] (/сводка) | Сгенерировать краткую сводку тикета для персонала |
| /incident add (/инцидент добавить) | Добавить активный сбой/инцидент |
| /incident list (/инцидент список) | Список активных инцидентов |
| /incident remove (/инцидент удалить) | Удалить решенный инцидент |
| /model show/set/save | Просмотр и смена рабочей AI-модели на лету |
| /reminders status/on/off | Управление напоминаниями персоналу в тикете |
| /config reload (/настройки перезагрузить) | Горячая перезагрузка settings.toml без рестарта |
| /ping (/пинг) | Проверка задержки до Discord |
| /help (/помощь) | Справка по командам |

## 📂 Структура проекта

`	ext
├── bot/                   # Основной пакет бота
│   ├── commands.py        # Слэш- и префиксные команды администратора
│   ├── discord_client.py  # Обертка над discord.py и отправка сообщений
│   ├── embeddings.py      # Загрузка SentenceTransformer и форматирование векторов
│   ├── escalation.py      # Детекция эскалации на оператора
│   ├── handlers.py        # Маршрутизация и обработка сообщений
│   ├── incidents.py       # Менеджер динамических инцидентов
│   ├── knowledge.py       # Загрузка и парсинг Markdown/JSON базы знаний
│   ├── limits.py          # Рейт-лимиты и анти-спам
│   ├── llm.py             # OpenRouter клиент, Vision и Fallback провайдер
│   ├── mention_moderation.py # Таймауты за запрещенные пинги
│   ├── rag.py             # Векторный и гибридный поиск по ChromaDB
│   ├── reminders.py       # Фоновые напоминания персоналу о тикетах
│   ├── settings.py        # Чтение и валидация settings.toml
│   ├── state.py           # Сохранение состояния тикетов в data/state.json
│   └── ticket_logs.py     # Логирование тикетов и авто-архивация
├── knowledge/             # База знаний (.md и .json файлы)
├── prompts/               # Системные промпты (system.md, summary.md)
├── scripts/               # Скрипты автонастройки (generate_settings.py)
├── tests/                 # Тестовый набор (>400 unit- и integration-тестов)
└── indexer.py             # Индексатор базы знаний в ChromaDB
`
