# Инструкция по игре с Bedrock Edition

## Адрес подключения
Для входа с телефона, планшета (Android/iOS) и консолей используйте адрес play.sinussmp.ru (порт 19132 по умолчанию). Для других стран: play.sinussmp.com.

## Особенности и голосовой чат
Голосовой чат Plasmo Voice работает только на Java Edition. На Bedrock голосовой чат не поддерживается.
